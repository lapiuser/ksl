# Kaliningrad School Leaderboard

Рабочий MVP: FastAPI + SQLAlchemy + SQLite локально / PostgreSQL на сервере, без отдельного frontend-сборщика.

## 1. Локальный запуск на Windows 11

Самый простой путь:

1. Распаковать папку проекта.
2. Дважды запустить `run_windows.bat`.
3. Открыть `http://127.0.0.1:8000`.

Батник сам создаст `.venv` и установит зависимости.

Ручной запуск:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

База по умолчанию создаётся в `data/leaderboard.db`. Она переживает остановку и перезапуск приложения.

## 2. Демо-активность

По умолчанию выключена.

Чтобы разово заполнить рейтинг искусственными кликами:

```powershell
.\.venv\Scripts\python.exe seed.py demo
```

Удалить только искусственную активность:

```powershell
.\.venv\Scripts\python.exe seed.py clear-demo
```

Можно также включить фоновую искусственную активность через `.env`:

```env
DEMO_ACTIVITY_ENABLED=true
```

Искусственные клики физически хранятся отдельно от реальных (`artificial_clicks` и `real_clicks`).

## 3. Что делает сервер

- единый общий рейтинг всех 75 учебных заведений;
- принимает пачки кликов, а не отдельный HTTP-запрос на каждый клик;
- серверный лимит — 800 засчитываемых кликов в минуту на браузерную сессию;
- не доверяет присланному числу сверх серверного лимита;
- считает посетителей и активные сессии;
- обновляет рейтинг примерно каждые 5 секунд;
- обновляет статистику примерно каждые 30 секунд;
- использует отдельные desktop/mobile изображения;
- раздаёт изображения с долгим cache-control;
- отдаёт health endpoint: `/health`.

## 4. Где менять текст «О проекте»

В одном месте: `app/config.py` (`ABOUT_TEXT`) или переменная `ABOUT_TEXT` в `.env`.

## 5. Перенос на нормальный сервер

На сервере можно использовать PostgreSQL без изменения API/фронтенда. Для контейнерного развёртывания уже есть `Dockerfile` и `docker-compose.yml`.

Для публичного сервера нужно:

- поставить `COOKIE_SECURE=true` под HTTPS;
- заменить `SECRET_KEY`;
- заменить пароль PostgreSQL;
- при отдельном frontend-домене заполнить `CORS_ORIGINS`;
- поставить reverse proxy/HTTPS перед приложением.

## 6. Важное по базе

Локальная SQLite-база находится в `data/leaderboard.db`. Не удаляйте этот файл, если хотите сохранить статистику.

При переходе с SQLite на PostgreSQL потребуется один раз перенести данные. Сам код при этом менять не нужно.

## 7. Проверка с телефона по Wi‑Fi

Для теста из локальной сети можно запустить `run_windows_lan.bat`. Узнай IPv4-адрес ПК через `ipconfig` и открой на телефоне `http://IP_ПК:8000`.

## 8. Резервная копия локальной базы

```powershell
.\.venv\Scripts\python.exe backup_db.py
```

Копия появится в `backups/`.


## Бесплатный тестовый запуск

Для временного публичного теста этот проект можно развернуть как FastAPI Web Service на Render Free. Render поддерживает Python/FastAPI и выдаёт бесплатный `onrender.com` адрес. Учти: бесплатный сервис уходит в sleep после 15 минут без входящих запросов, а локальные файлы (включая SQLite) не являются постоянным хранилищем. Для временного теста это подходит, для рабочего запуска — нет.

Для продакшена лучше перейти на VPS и PostgreSQL.
